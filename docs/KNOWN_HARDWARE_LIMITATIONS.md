# Known hardware limitations
El control físico queda `NOT PROVEN — EXTERNAL DEPENDENCY` hasta disponer de equipo, target explícito, credencial y recuperación. El simulador siempre se marca `SIMULATED`.

Discovery LAB valida el pipeline de software con ICMP/SNMP/fingerprint simulado, observaciones y correlación; no prueba que un router físico acepte cambios. Las acciones persisten `ProvisioningStatus.Unsupported` cuando no existe un driver verificable.

Para cerrar esta limitación externa se necesita equipo autorizado, firmware/modelo, credencial no versionada, target de laboratorio y comprobación posterior de estado. No se infiere control desde una respuesta HTTP.
